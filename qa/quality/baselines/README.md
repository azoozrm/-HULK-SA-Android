# Visual baselines

No post-upgrade visual baseline is approved yet. The pre-upgrade Compatibility Lab run is evidence
for diagnosis only and cannot be promoted because it is incomplete and has known false negatives.

An approved baseline directory must include Before screenshots, a manifest with `approved: true`,
the exact 40-character build SHA, device/API/density/font scale, threshold, masks, reviewer, and
reason. PR workflows cannot create or update it.
